# Data Provenance

The platform distinguishes `OBSERVED`, `CALCULATED`, `DERIVED`, `INTERPOLATED`, `SYNTHETIC`, and `USER_INPUT`. Source links are attached to historical observations and causal graph edges where the Case Pack provides them.

The UK LDI portfolio example is a `SYNTHETIC` learning exercise. It combines real event observations with a hypothetical position to teach DV01. It is not evidence of an actual pension fund or bank position.
